Guía de Modular Synth

Inicio rápido

  1. Pulsa Start para activar el audio.
  2. Añade módulos desde la paleta (categorías) o clic derecho.
  3. Conecta salida → entrada arrastrando sockets.
  4. Básico: Keyboard.CV→VCO.Freq, Gate→ADSR, VCO→VCA←ADSR, VCA→Output.
  5. Prueba Ejemplos.

Tipos de cable

  • audio señal
  • cv control
  • gate disparo

Cableado y VCA

CV al VCA se suma al AudioParam: el VCA con CV usa base 0 y el ADSR abre el volumen. Level es el tope.

Conexiones lista y borra cables. Polifonía: módulo Voices + cadena por voz.

Generadores

  • VCO — + ring mod
  • Additive — Fourier, stretch, inharm
  • FM / DX7 FM — 2 ops o 6 ops + 32 algos + EG
  • Wavetable — morph, carga WAV/JSON
  • LA — PCM + Upper/Lower
  • Sample / Granular — sample y granos
  • Noise

Procesadores y moduladores

  • VCF, VCA, Mixer, Delay, Chorus, Reverb
  • ADSR, LFO

Control

  • Keyboard (HOLD, PC keys), Sequencer, Arp, Voices, MIDI CC, Output

MIDI

Selecciona dispositivo en MIDI In. Notas al Keyboard/Voices. MIDI CC Learn para knobs.

Patches

Export/Import JSON. Ejemplos en examples/. Diagrama → PDF.

Canvas

Scroll H/V. Zoom −/+ o Ctrl+rueda. Arrastre por cabecera del módulo.

Acerca de Modular Synth

Modular Synth es un sintetizador modular que se ejecuta por completo en el navegador (HTML, CSS y JavaScript + Web Audio API). Está inspirado en entornos como SynthEdit, FlowStone o un rack Eurorack: añades módulos, los unes con cables y el sonido se genera en tiempo real.

Motor de audio

  • Web Audio API como motor principal, con selección de sample rate (44,1 / 48 / 96 kHz).
  • Salida real a los altavoces del sistema tras pulsar Start (requisito de los navegadores).
  • Medidor de nivel en el módulo Output.

Módulos de síntesis

  • Additive: síntesis aditiva / Fourier (hasta 16 parciales, tilt, odd/even, stretch).
  • LA: estilo Roland Linear Arithmetic (PCM attack + synth, mix/ring/xfade, TVF/TVA).
  • VCO: oscilador (sine, saw, square, triangle), frecuencia, detune, FM, y ring modulation (mezcla dry/wet y ratio; entrada Ring In opcional).
  • VCF: filtro multimodo (lowpass, highpass, bandpass, notch) con cutoff, resonancia y CV de corte.
  • VCA: amplificador controlado por CV (ideal con la salida del ADSR).
  • ADSR: envolvente Attack / Decay / Sustain / Release, disparada por Gate (respeta velocity).
  • LFO: oscilador de baja frecuencia para modular cutoff, amplitud, etc.
  • Noise: ruido blanco (base para percusión y texturas).
  • Mixer: mezcla de hasta 3 señales con niveles por canal y master.

Sample

  • Carga de archivos WAV, MP3 u OGG.
  • Control de pitch mediante Freq CV (compatible con teclado y secuenciador, en Hz).
  • Root key, detune, gain, loop y retrig al recibir gate.
  • ADSR interno sobre el volumen del sample.
  • Filtro resonante (LP / HP / BP) con cutoff, resonancia y entrada CV de corte.

Control y secuencia

  • Keyboard: al menos 4 octavas en pantalla, ratón, teclado QWERTY y Web MIDI (Note On/Off con velocity).
  • Arpeggiator: modos Up, Down, Up-Down y Random; 1–3 octavas; rate, longitud de gate y latch.
  • Sequencer: hasta 32 pasos, longitud configurable, sliders verticales por nota, BPM, play/stop; salidas CV y Gate.
  • MIDI CC: módulo visual con Learn CC / Learn Param, mapeo a knobs de otros módulos, min/max y feedback de nivel.

Efectos

  • Delay: tiempo, feedback y mix.
  • Chorus: rate, depth y mix.
  • Reverb: decay y mix (respuesta a impulso generada en el navegador).

Interfaz y patches

  • Paleta de módulos, arrastre, clic derecho para añadir, cables curvados (SVG) por tipo: audio, CV, gate.
  • Tabla de conexiones: listado de todos los cables y borrado individual.
  • Export / Import JSON del patch completo (módulos, parámetros y cables).
  • Menú Ejemplos: carga presets desde la carpeta examples/ (manifiesto + descubrimiento dinámico en GitHub Pages).

Uso rápido

  1. Pulsa Start para iniciar el AudioContext.
  2. Añade módulos desde la izquierda o con el menú contextual.
  3. Conecta arrastrando de un socket de salida a uno de entrada.
  4. Patch básico: Keyboard → VCO → VCA; Keyboard Gate → ADSR → VCA CV; VCA → Output.
  5. Explora presets en Ejemplos o revisa cables en Conexiones.
